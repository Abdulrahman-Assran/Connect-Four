# 🔴🟡 Java Console Connect Four

A terminal-based Connect Four game built in **Java**, focusing on matrix manipulation, gravity mechanics for token drops, and win-detection algorithms.

## 🎮 Features
- Interactive column-selection interface.
- Simulated gravity mechanics (discs automatically fall to the lowest available row in a column).
- Horizontal, vertical, and diagonal win-condition checks.

## 🛠️ Concepts Applied
- 2D Arrays/Matrices manipulation.
- Algorithmic board scanning for matching sequences.
- Clean separation of UI logic and game rules.

## 💻 How to Run
Compile and run the project files using any Java IDE or command-line compiler.
